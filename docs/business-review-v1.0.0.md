## 本轮已修复

1. 取消应用可能显示绿色“壁纸已应用”：后台结果显式携带取消状态，前台改为取消提示；状态读取失败也不显示应用成功。
2. 导入、重命名、删除、排序重复查询 Codex 注册信息及调试会话：这些本地操作复用最近一次检测结果；刷新、应用和恢复仍执行必要检测。
3. 分类切换和排序时重复解码缩略图：使用文件路径、大小、修改时间和解码尺寸作为缓存键，复用冻结的 BitmapImage，最多保留 64 项。
4. 选中图片即解码大图：预览未打开时优先复用缩略图；打开效果预览后再读取大图。
5. 失效或不可读取的 Wallpaper Engine 根目录中断批量导入：逐目录记入失败报告并继续扫描其他目录。
6. 跳过更新后旧清单仍保留：清除 UI 中的 AvailableUpdate，手动检查仍可重新获取。
7. 启动器 PE 文件版本仍是 0.3.0：同步到 1.0.0.0；升级完成提示不再引用已删除的“打开 Codex”按钮。
8. 默认窗口过大：按用户截图改为可用桌面宽/高约束的 85%，保持 12:7、居中，最小 900×525。
9. 安装验收脚本仍使用旧窗口标题，且启动后重复创建已存在的库目录：同步测试契约，确保实际执行安装、启动、升级与卸载链路。

## 仍然适用的限制

- Wallpaper Engine Scene/Web/Application 不支持；视频格式兼容性仍受 Windows 媒体组件限制。
- 预览是模拟 Codex 效果，不是临时注入当前工作的 Codex 窗口。
- 长按拖动逻辑、DPI 位移和交换保存已测试，但后台 Cua Driver 不支持 WPF 鼠标拖拽，真实鼠标端到端手感仍依靠用户验收。
- 本轮安装验收使用独立目录和测试 AppId，不覆盖用户当前安装。实际运行的 Codex 未被重启。
- 尚未公开发布，旧版通过线上 latest 接收 1.0.0 并下载的网络端到端验证须在最终发布后进行。
