# 2.1.0

2.1.1 的兼容性修复和稳定性改进请参阅 [CHANGELOG](../../CHANGELOG.md)。

- 安装时可选择位置，重装默认沿用原目录，自动更新保留安装位置。
- Steam 图片和兼容视频直接引用 Steam 库源文件，不再额外保存媒体副本；仅保存索引和缩略图，Steam 视频关闭持久缓存。本地导入仍保存独立副本。
- Steam 源文件不可用时从壁纸列表隐藏；若正作为背景使用，下次打开 Codex 恢复初始外观。源文件重新可用后刷新可再次显示。
- 修复健康隐藏窗口被误判为启动失败的问题，增加独立恢复记录，连接丢失后重新发现和验证 Codex 会话；恢复初始外观、升级与卸载同步处理恢复记录。
- 管理中心打开后自动尝试连接，保留必要的重启确认；采用已确认的弹窗排版、重命名校验与艺术字调整。
- 新安装默认目录和发行包主名称统一为 `CodexPage`；旧安装目录、更新器下载文件名、互斥量和数据格式保留兼容别名，升级不会丢失壁纸库或设置。

升级建议：退出 CodexPage 后运行安装包，沿用原安装位置覆盖升级，无需卸载。升级后重新应用一次壁纸，以建立新版恢复记录。更改安装目录不会自动搬迁旧壁纸库。

Steam 视频直引仅支持通过兼容性检查的 H.264 MP4（不超过 1080p、60fps、128MiB）；不兼容视频不会为了导入而额外转码复制。旧版正在使用的 Steam 副本暂缓迁移，既有不兼容转码副本不会自动删除。

第三方入口说明：具有可验证连接端口的 Codex 会话可由监控重新连接；没有连接端口的已运行会话仍需通过 CodexPage 确认连接，可能需要重启。此版本不保证所有第三方启动方式或系统休眠场景均可无感恢复。
