# CodexPage 1.2.1

**此次更新请前往本 GitHub 发布页下载 `Codex-Skin-Manager-Setup.exe`，退出 CodexPage 后运行安装包覆盖升级。旧版暂勿使用“立即更新”。**

旧版更新器存在关闭冲突，无法靠尚未安装的新版本修复自身。无需卸载或删除壁纸库，覆盖升级保留壁纸与设置。

- 修复升级时“CodexPage 尚未退出，已停止升级”的问题。
- 安装辅助进程异常退出时保留 CodexPage，允许重试。
- 启动超时时清理本次辅助进程，避免与后续重试冲突。
- 补齐视频缓存运行依赖。
- 新版界面支持以深红色强调升级方式提示；旧版仍以原有颜色显示提示文字。

本版应用内更新通知也会显示上述手动升级提示。
