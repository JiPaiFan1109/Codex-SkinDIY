## 安装与升级

下载下方 `Codex-Skin-Manager-Setup.exe`，先退出正在运行的应用及预览窗口，再覆盖安装，无需卸载。较早版本请使用此手动升级方式。此前安装过本地测试版 2.0.0 的用户也需手动覆盖安装，同版本号不会触发自动更新。

安装与运行文件名保留兼容名称，应用显示为 CodexPage。ZIP 包为便携安装材料，完整解压后运行 `Install.cmd`；GitHub 自动生成的源码包不含 Node 运行时。

本项目为社区独立工具，非 OpenAI 官方产品。支持 Windows x64 和官方 Microsoft Store 版 Codex。第三方示例壁纸不作为预置素材分发。
