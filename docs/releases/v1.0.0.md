1. CodexPage 界面升级：浅蓝色画廊、透明图标、统一确认框与提示，默认居中显示并留出桌面空间。
2. 能够自动批量引入本地 Wallpaper Engine 壁纸：发现多个 Steam 库，支持手动选择改名后的目录；视频/图片与手动导入分别展示。
3. 增加 Codex 效果预览、长按拖动窗口、壁纸交换排序并保存，以及四角等比例缩放。
4. 优化导入与浏览速度：兼容 H.264 MP4 无需转码，重复素材提前识别，缩略图缓存复用，减少多余连接检测。
5. 新版更新提示同时显示新版本、当前版本与主要更新内容，保留签名校验和壁纸收藏。
6. 修复取消应用后的成功误报、失效目录中断批量扫描及跳过更新的残留状态。
7. 扩大空白区域拖动范围，提高响应速度；批量导入结果改为一次性确认弹窗，不再占用壁纸画廊。
8. 优化 Codex 启动与壁纸应用：修复静态壁纸快速恢复，复用可用服务，减少连接超时和无效等待，并改善重启提示。

兼容说明：支持 Wallpaper Engine 视频与图片项目；Scene、Web、应用项目暂不支持。部分视频仍需 Windows 媒体组件转码，无法解码时会明确报告，不会阻止其他可用项目导入。

0.3.0 用户可在 CodexPage 检查更新；更早版本请手动运行安装程序。升级保留壁纸库与设置，不自动关闭 Codex。应用壁纸会启动或连接 Codex，必要重启会请求确认。
