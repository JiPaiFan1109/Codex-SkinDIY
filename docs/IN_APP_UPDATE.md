# 应用内更新（第九版草稿）

用户点击“立即更新”后，CodexPage 自动下载、校验更新包；下载显示真实百分比，校验和安装显示阶段进度。安装前保存未落盘的清晰度设置。更新安装窗口准备好后，旧 CodexPage 退出，由独立程序静默执行安装，验证目标版本后显示完成，并重新打开 CodexPage。安装时不自动重启 Windows 或 Codex。

安装窗口未成功启动时保留旧 CodexPage。下载失败可以重试；安装失败显示错误并提供返回 CodexPage 入口，不显示虚假的完成状态。签名、固定发布源、长度和 SHA-256 校验继续保留。安装窗口不能在写入过程中随意关闭。

应用内更新仍会下载安装包，但不要求用户打开浏览器、寻找下载目录或手动运行安装程序。首次安装、旧版没有更新器、更新器自身损坏或自动下载始终不可用时，手动安装仍是备用方式。

## 验证范围

- app-update.tests.ps1：版本策略、签名及损坏包拒绝。
- update-flow.tests.ps1：模拟在线/离线检查；真实测试可执行文件验证静默安装参数、失败返回、版本检查及用户文件保留。
- update-staging.tests.ps1：已签名测试包通过下载边界校验，新进度窗口的全部依赖被放入独立目录。
- update-progress.tests.ps1：真实 WPF 调度与独立工作线程，测试安装成功、失败、窗口就绪握手及返回操作；仅安装器边界使用测试替身，不进行真实产品更新。
- update-ui.tests.ps1：进度条、跳过和稍后；1440×840 和 900×525 渲染检查。
