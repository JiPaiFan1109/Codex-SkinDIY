## 限制与待确认项

- Scene、Web、Application 类型尚不支持。某些视频依赖 Windows 解码器；本机一个 4K 视频转码失败，不能承诺全部 Wallpaper Engine 壁纸可用。
- 全套测试初次因 C 盘容量不足失败；改用 D 盘独立临时目录后全套通过。没有清理用户其他目录。
- Cua Driver 对最小化测试窗口拒绝后台截图/点击；没有恢复焦点或接管鼠标。外观依据 WPF 实际渲染与集成测试，不能把 Cua 这一项记为通过。
- 未对用户当前安装进行覆盖升级，也未重启本轮正在使用的 Codex；正式安装器的实际覆盖安装、真实 Codex 应用验收可作为用户追加项目。
